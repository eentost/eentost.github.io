계산기 입력

현재 계산기의 입력 숫자와 날짜는 방문자의 브라우저에서만 처리합니다. 별도 회원가입이나 입력 데이터 저장 서버는 운영하지 않습니다.

프롬프트 생성기 입력

상황별 프롬프트 생성기는 사용자가 입력한 상황 설명과 선택 항목을 브라우저 안에서 조합합니다. 입력 정보는 사이트 서버로 전송하거나 저장하지 않습니다. 이용자가 생성된 내용을 외부 AI 서비스에 직접 붙여 넣은 이후의 정보 처리에는 해당 서비스의 정책이 적용됩니다.

호스팅 및 접속 정보

이 사이트는 GitHub Pages를 통해 제공되며, 호스팅 제공자의 접속 처리에 관한 사항은 GitHub 개인정보 보호정책을 참조하세요.

광고·쿠키

Google AdSense 확인용 메타 태그와 ads.txt 파일이 있으나 그 자체로 계산기 입력값을 수집하지 않습니다. Google Analytics 4 방문 통계는 운영자가 GA4 측정 ID를 연결해야 활성화되며, 방문자가 분석 통계 수집에 동의한 뒤에만 Google 분석 스크립트를 로드합니다. 페이지 및 도구 사용 횟수만 직접 전송하고 계산기 입력 숫자, 프롬프트 텍스트, 계산 결과를 이벤트 매개변수로 보내지 않습니다. 분석 동의 이후 쿠키와 브라우저 정보는 Google 정책에 따라 처리될 수 있습니다. 각 페이지 아래의 방문 통계 설정에서 동의를 거부하거나 철회할 수 있습니다. 거부해도 모든 도구를 사용할 수 있습니다. 브라우저 추적 보호로 인해 통계가 집계되지 않을 수 있습니다. 실제 광고 도입 시 별도 고지와 동의 절차를 검토합니다.
