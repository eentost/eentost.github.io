브라우저 계산기

경보량 계산기는 방문자가 입력한 숫자를 브라우저 안에서 계산하며, 사이트 자체 서버로 전송하는 코드는 포함하지 않습니다.

호스팅

사이트는 GitHub Pages에서 정적 페이지로 제공됩니다. 호스팅 서비스 제공자의 접속 기록 처리 사항은 GitHub 개인정보 보호 고지를 확인하세요.

광고와 분석

이 새 버전에는 Google AdSense 광고 스크립트와 Google Analytics 태그를 삽입하지 않았습니다. 향후 적용 시 관련 쿠키, 제3자 처리 및 선택권 안내를 업데이트해야 합니다.
