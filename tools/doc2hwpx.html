DOCX를 HWPX로 변환하는 방법

워드 문서를 HWPX로 변환하려면 위에서 DOCX 파일을 선택하고 변환 버튼을 누른 뒤, 생성된 HWPX 파일을 다운로드하세요. 브라우저에서 생성한 문서의 내부 ZIP·XML 구조를 다시 확인하지만, 실제 한컴오피스에서 편집·렌더링한 결과까지 동일하다고 보장하는 검증은 아닙니다.

지원되는 입력 파일 형식

이 웹 체험판은 DOCX, Markdown(MD), HTML, TXT, CSV 파일을 선택할 수 있습니다. 구형 DOC와 PDF 파일을 직접 업로드해 변환하는 기능은 웹 체험판에서 제공하지 않으며, 화면에 표시된 샘플과 실제 지원 기능을 구별해야 합니다.

문서 변환 시 주의할 서식

문단·제목·단순 표 중심으로 변환됩니다. 복잡한 페이지 배치, 병합된 표, 그림, 수식, 글자별 서식은 원본 그대로 보존되지 않을 수 있습니다. 업무 제출 전에는 실제 한컴오피스에서 파일을 열어 서식과 내용을 확인하세요.

자주 묻는 질문: PDF를 HWPX로 바로 변환할 수 있나요?

현재 브라우저 체험판에서는 PDF를 직접 변환할 수 없습니다. PDF/DOC 형식의 비교 샘플과 웹에서 직접 선택 가능한 형식은 다르므로, 입력 파일 선택 창의 지원 확장자를 확인하세요.

자주 묻는 질문: 파일이 서버에 업로드되나요?

이 페이지의 문서 변환은 브라우저 내부에서 처리하도록 설계되어 있습니다. 파일을 선택할 때 외부 서버로 보내는 기능은 제공하지 않습니다. 민감한 문서는 별도 검증된 환경에서 처리하세요.
