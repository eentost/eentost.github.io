INTERACTIVE LAB 01

AI 탐지 경보량 계산기

모델의 재현율과 오탐률이 같아도 실제 이상 발생 비율이 낮으면 경보 대부분이 오탐일 수 있습니다. 아래 숫자를 바꿔 하루 경보량과 분석 시간을 계산해 보세요.

입력값은 사용자 브라우저에서만 계산합니다. 결과는 기대값이며 실제 성능이나 측정된 운영 데이터가 아닙니다.

계산 방법

예상 실제 이상 건수는 전체 이벤트 × 이상 비율입니다. TP = 이상 건수 × 재현율, FN = 이상 건수 − TP, FP = 정상 건수 × 오탐률, TN = 정상 건수 − FP입니다. 경보 수는 TP + FP, 정밀도는 TP / (TP + FP)이며 경보 검토 시간은 경보 수 × 건당 검토 시간입니다.

해석 시 주의

이 계산은 동일한 기준으로 독립 이벤트를 평가하고, 설정한 탐지율과 오탐률이 해당 운영 환경에도 유지된다고 가정합니다. 중복 경보, 사건 병합, 탐지 지연, 조사 난도, 모델 변화, 라벨 오류는 반영하지 않습니다. 현장 도입 판단에는 시간 구간과 고객·조직 단위로 분리한 실제 검증이 필요합니다.

공식 참고
