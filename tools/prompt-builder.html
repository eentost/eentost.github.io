상황별 AI 프롬프트 생성기

무엇을 어떻게 요청할지 막막하다면 상황을 선택하세요. 목적·제약·결과 형식을 반영하는 요청문을 만들고 복사할 수 있습니다.

안내: 이 도구는 AI 답변을 직접 생성하지 않습니다. 상황별 규칙에 따라 프롬프트 텍스트를 브라우저 안에서 조합합니다. 서버 전송·계정 등록은 없으며, 비밀번호·개인정보·내부 기밀은 입력하지 마세요.

1. 어떤 상황인가요?

2. 답변 방식

3. 생성 결과

필수 입력 필요

필수 내용을 입력해 주세요.

결과는 AI에 전달할 요청문입니다. 최종 AI 답변에 포함된 사실과 출처는 별도로 검증해야 합니다.

어떤 원리로 만드나요?

상황에 적합한 역할 → 목적 → 입력된 사실과 조건 → 수행 원칙 → 출력 형식 → 검증 기준을 조합합니다. 단순한 키워드 입력보다 구체적인 결과를 요청할 수 있지만, 실증적인 정확도 향상을 보장하는 기술은 아닙니다.

막연한 요청과 차이점

일반 요청

“협력사에 메일을 써줘.”

상황별 요청

“외부 협력사 담당자에게 납기 일정을 1주 조정해 달라고 정중히 요청하되, 내부 품질 검증에 5영업일이 필요하다는 사실을 포함하고 확인되지 않은 약속을 피하도록 메일을 작성해 줘.”

안전하게 사용하는 법

이 도구에서는 입력 내용이 서버로 전송되지 않지만, 생성된 프롬프트를 외부 AI 서비스에 전송하면 해당 서비스 정책이 적용됩니다. 개인정보·고객 정보·비밀번호·기밀 문서는 익명화하거나 제거하세요. 실제 출처나 조사 결과를 확인하지 않고 그대로 게시하지 마세요.

AI 프롬프트를 잘 작성하는 4가지 요소

좋은 프롬프트는 목적, 입력 자료, 제약 조건, 원하는 출력 형식을 분명하게 전달합니다. 예를 들어 '회의 정리해 줘'보다 '아래 회의 메모를 결정 사항·담당자·마감일 표로 정리하고 확인되지 않은 내용은 미확정으로 표시해 줘'가 더 구체적입니다.

업무용 프롬프트 예시

“다음 내용을 바탕으로 거래처에 보낼 정중한 이메일을 작성해 줘. 목적은 일정 변경 안내이며, 확정되지 않은 일정은 임의로 만들지 말고 확인 필요라고 표시해 줘. 결과는 제목과 본문으로 나눠 줘.”

자주 묻는 질문: 이 도구가 AI 답변도 생성하나요?

아닙니다. 선택한 상황과 입력 내용을 바탕으로 AI에 전달할 요청문 텍스트를 구성하는 도구입니다. 생성된 요청문을 원하는 AI 서비스에 직접 붙여 넣어 사용하세요.

자주 묻는 질문: 회사 기밀이나 개인정보를 넣어도 되나요?

민감한 정보는 입력하지 않는 것이 안전합니다. 이 도구 자체는 브라우저에서 문구를 조합하지만, 결과를 외부 AI 서비스에 붙여 넣으면 해당 서비스의 데이터 처리 정책이 적용됩니다.
