문의 및 정정 요청

콘텐츠 오류, 출처 누락, 접근성 문제와 개선 제안을 접수합니다.

정정 요청에 포함하면 좋은 내용

  • 문제가 있는 페이지 주소
  • 오류가 있다고 생각하는 문장 또는 표
  • 확인 가능한 근거 자료나 원문 링크
  • 화면 표시 오류라면 사용 기기와 브라우저 정보

개인정보, 비밀번호, 계정 정보 등 민감한 내용은 보내지 마세요.

연락 경로

콘텐츠 오류나 접근성 문제는 초록한칸 GitHub Issues에서 공개 이슈로 남길 수 있습니다. 이슈를 작성하려면 GitHub 로그인이 필요하며, 작성한 내용은 공개됩니다.

별도 비공개 문의 채널은 현재 제공하지 않습니다. 개인을 식별할 수 있는 내용은 빼고, 문제가 있는 페이지 주소와 정정이 필요한 부분만 남겨주세요.
