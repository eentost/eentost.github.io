# 하루도구 방문자·이용 통계 연결 가이드

## 현재 상태
전 페이지에 동의 기반 분석 모듈을 연결했습니다. `assets/analytics-config.js`의 측정 ID가 비어 있으면 **실제 수집은 비활성**입니다.

## 관리자 설정
1. https://analytics.google.com/ 에 로그인해 GA4 웹 데이터 스트림을 생성하거나 기존 스트림을 엽니다. 사이트 URL: https://eentost.github.io
2. 관리 > 데이터 스트림 > 웹 스트림에서 **G-...** 측정 ID를 복사합니다.
3. `assets/analytics-config.js` 파일의 `measurementId: ''`에 ID를 입력하고 배포합니다. 비밀키나 인증 토큰을 삽입하지 마세요.
4. GA4 향상된 측정 기능에서 **사이트 검색 및 양식 상호작용 측정**을 끄거나 전체 자동 측정 항목을 검토하세요. 사이트는 입력값, 쿼리 매개변수, 프롬프트 텍스트를 직접 보내지 않는 이벤트만 구현합니다.
5. 시크릿 창에서 확인: 동의 전에는 Google 태그 요청이 없어야 합니다. 동의 후 네트워크 탭에 gtag/js 및 GA 수집 요청이 표시되고 GA4 실시간 보고서에 page_view가 나타나야 합니다. 거부, 동의 철회 및 새로고침 동작도 검증하세요.

## 이벤트 정의
- `page_view`: 동의 후 페이지 진입. 페이지 제목·경로·쿼리 없는 URL·쿼리 없는 참조 주소.
- `tool_use` / `calculate`: 사용자가 계산기 값을 바꾸고 1.1초 이후 유효한 결과가 나올 때. 2.5초 내 반복 집계 방지.
- `tool_use` / `copy_click`, `download_click`: 프롬프트 생성기 복사/저장 버튼 클릭. 성공 완료가 아니라 버튼 클릭 집계입니다.
- 직접 전송하지 않는 것: 계산 원본 값, 계산 결과, 프롬프트 입력문/출력문, 이메일, 사용자 계정 식별자.
- GA4의 실제 방문자 수는 동의 거부자, 스크립트 차단, GPC 사용자를 포함하지 않으므로 전체 방문자의 절대 수가 아닙니다.

## 비공개 보고서
- GA4: https://analytics.google.com/ (Google 계정 권한으로 접근 보호)
- Google Search Console: https://search.google.com/search-console/ (별도 소유권 확인 후 검색 유입 분석)
- GitHub Insights/Traffic은 저장소 방문 통계이며 사이트 트래픽이 아닙니다.
- GitHub Pages 정적 사이트 안에 가짜 관리자 로그인 화면을 두지 않습니다. 안전한 관리자별 데이터 확인은 인증된 GA4에서 수행합니다.

## 코드 검증 및 운영 범위
분석 ID가 비어 있을 때 외부 분석 요청이 발생하면 안 됩니다. 동의 전 요청 금지, 동의 이후만 page_view/tool_use, 거부 시 수집 안 함, 철회 시 쿠키 삭제 및 재로드, 기존 계산기·프롬프트 회귀 검증을 확인하세요. 계정 측정 ID가 없으면 수집/실시간 보고서 E2E 테스트는 수행할 수 없습니다.
